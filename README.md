# ⚖️ IPC 1860 Chatbot

A simple PDF-based chatbot that answers questions from the **Indian Penal Code, 1860** using **Hugging Face LLM** and RAG.

## Features

- 📄 Upload IPC 1860 PDF
- 🔎 Search relevant sections
- 🤖 Hugging Face LLM
- ⚖️ Exact IPC section search
- 📚 PDF page references
- 💬 Interactive Streamlit chatbot

## Technologies

- Python
- Streamlit
- Hugging Face
- FAISS
- Sentence Transformers
- PyPDF

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
